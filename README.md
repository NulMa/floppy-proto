# floppy-proto

2PG 아케이드 **1.44MB 게임 공모전** 출품작 (마감 2026-09-04).

> **1.44MB 안에 무엇을 담을지 고르고, 포맷에 쫓기며 그 선택으로 길을 뚫는 플랫포머.**

```
fetch-deps.bat   raylib 소스를 받는다 (새로 클론했을 때 한 번만)
build.bat        빌드 (raylib 이 없으면 소스에서 먼저 빌드 — 첫 회 1~2분)
build\floppy.exe 실행
test.bat         헤드리스 검증 (레벨 관문 vs 물리 수치 대조)
```

`vendor/` 는 90MB 라 저장소에 없다. **클론 직후에는 `fetch-deps.bat` 을 먼저 돌린다.**

## 조작

| 키 | 동작 |
|---|---|
| `←` `→` | 이동 |
| `Space` | 점프 (홀드로 높이 조절 · `glide` 장착 시 홀드로 활공) |
| `Shift` | 대시 (`dash` 장착 시) |
| `1`~`5` | 능력 교체 — **터미널 위에서만** |
| `R` | 재시작 |
| `[` `]` | BGM 볼륨 (10%씩) |
| `-` `=` | 효과음 볼륨 (10%씩) |
| `M` | BGM 켜기/끄기 |
| `F5` | `tune.txt` 재로드 (재빌드 없이 감각 수정) |

볼륨은 기본 **30%** 이고 `save.dat` 에 같이 저장된다.

## 규칙

용량은 **12칸 = 1,474,560 B.** 능력은 파일이고 칸을 먹는다. 합이 20칸이라 **항상 두고 가야 한다.**

| 키 | 파일 | 칸 | 효과 |
|---|---|---|---|
| 1 | `jump2.exe` | 5 | 2단 점프 |
| 2 | `dash.exe` | 4 | 공중 대시 |
| 3 | `glide.exe` | 4 | 활공 |
| 4 | `grip.exe` | 4 | 벽 붙기 + 벽 점프 |
| 5 | `boot.exe` | 3 | 점프력 +20% |

- **터미널(초록)에서만 로드아웃을 바꿀 수 있다.** 밖에서 누르면 거부된다
- 터미널은 체크포인트를 겸한다. 밟으면 **포맷 파동이 멈추고 뒤로 물러난다**
- **포맷 파동**이 왼쪽에서 계속 밀고 온다. 닿으면 마지막 터미널에서 재시작

터미널에서 앞을 보고 → 로드아웃을 정하고 → 커밋하고 출발한다. 출발하면 그때부터 쫓긴다.

## 구간마다 두 갈래 길

| 구간 | 길 A | 길 B |
|---|---|---|
| 1 세로 장벽 9칸 | `grip` 직등 | `boot`·`jump2` 로 3칸 발판 |
| 2 구덩이 6칸 ×2 | `dash` | `jump2` |
| 3 | `grip` 으로 위층 등반 | `dash`·`glide` 로 저천장 통로 |

**어떤 능력도 단독으로 전 구간을 못 연다.** 관문마다 답을 여러 개 두는 방식으로는
이게 안 된다 — `jump2` 가 높이도 거리도 1위라 항상 상위호환이 되기 때문이다. **길 자체를 갈라야 한다.**

이건 `test.bat` 이 매번 검사한다. 새 구간을 만들 때마다 깨지지 않았는지 확인할 것.

## 구조

```
src/sim.c    게임 규칙 전부. raylib 을 한 줄도 안 쓴다
src/sim.h    Tune 구조체 = 감각 수치의 계약
src/main.c   창·입력·렌더링만
src/test.c   헤드리스 검증 (제출물 아님 → 1.44MB 예산에 안 들어감)
tune.txt     감각 수치. F5 핫리로드
docs/        결정·스펙·진행로그·AI 지시 아카이브
```

`sim.c` 가 raylib 을 모르기 때문에 헤드리스로 컴파일해서 검증할 수 있다.
**레벨은 문자열이 아니라 사각형 목록(`BOXES`)으로 짓는다** — 96자를 손으로 못 맞춘다.

### 빌드 주의

- **`/MT` 정적 CRT 필수.** 공식 raylib 배포 lib 은 `/MD` 라 그대로 쓰면 VC++ 재배포 패키지 의존이 생긴다.
  `build-raylib.bat` 이 소스에서 `/MT` 로 다시 빌드한다
- `.bat` 파일은 **CRLF** 로 저장할 것. LF 면 cmd 가 토큰을 깨먹는다
