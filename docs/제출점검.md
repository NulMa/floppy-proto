### 2. 런타임이 정말 안 붙나

```

  GDI32.dll  WINMM.dll  USER32.dll  SHELL32.dll  KERNEL32.dll
```

전부 Windows 가 기본으로 들고 있는 것이다. `MSVCP140.dll`·`VCRUNTIME140.dll` 이 없다 —
`/MT` 로 CRT 를 정적 링크했기 때문이다. **VC++ 재배포 패키지가 필요 없다.**
