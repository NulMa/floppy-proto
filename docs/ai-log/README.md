# AI 지시 아카이브

> **나중에 복원할 수 없다.** 그날 남긴다.

파일 규칙: `docs/ai-log/YYYY-MM-DD_D+n_주제.md`

형식: 맥락 / 지시 원문 / 결과 / 사람의 개입(받아들인 것 · 되돌린 것 · **왜 그렇게 판단했는가**)

## 원칙 4개

1. **다듬지 않는다.** 오타·반말·중간에 끊긴 지시 그대로. 정제하면 사후 가공이 된다
2. **실패한 지시를 반드시 남긴다.** 성공만 나열하면 프로세스 설계가 아니라 **운으로 읽힌다**
3. **판단 근거를 적는다.** "고쳤다"가 아니라 **"왜 그게 틀렸다고 봤는가"**
4. **비밀정보 금지**

## 이 프로젝트의 특이사항

작업 분담이 처음부터 명시됐다 — **사람: 기획·디렉팅·아트·지시 / AI: 기능 구현.**
그래서 이 로그의 "지시 원문"은 대부분 **판정과 방향 전환**이고, 구현 세부는 거의 없다.

D+1 에 코어가 한 번 통째로 교체됐다. 그 판정의 근거가 이 아카이브의 핵심이다.
