LAST WRITE
2PG 아케이드 1.44MB 게임 공모전 출품작

  floppy.exe 하나만 실행하면 됩니다.
  설치도, 외부 파일도, VC++ 재배포 패키지도 필요 없습니다.
  진행 상황은 실행 파일 옆에 save.dat 으로 저장됩니다.


■ 이 게임이 무엇인가

  1.44MB 플로피 디스크가 주인공입니다. 화면은 디스크 안이고,
  뒤에서 포맷 파동이 쫓아옵니다.

  능력은 boot.exe / dash.exe 같은 "파일"이고 용량 12칸을 나눠 먹습니다.
  전부는 못 들고 갑니다. 무엇을 들고 갈지 고르는 것이 이 게임입니다.

  로드아웃은 터미널에서만 바꿉니다. 터미널을 떠나면 파동이 다시 움직입니다.
  20개 섹터, 각 섹터마다 회수할 파일이 하나씩 있습니다.


■ 조작

  방향키          이동
  Space           점프 (길게 누르면 더 높이)
  Shift           dash.exe
  1 ~ 5           터미널에서 유틸리티 장착 / 해제
  R               재시작
  Esc             나가기 (플레이 → 섹터 목록 → 타이틀)

  [ ]             BGM 음량
  - =             효과음 음량
  M               BGM 음소거
  Alt + Enter     전체화면


■ 용량

  실행 파일      1,039,872 B
  이 폴더 전체   1,046,151 B  (1,474,560 B 한도의 70.9%)

  아트, 효과음, 음악, 20개 레벨이 전부 실행 파일 안에 있습니다.
  효과음과 음악은 파일이 아니라 코드가 실행 중에 합성합니다.
  raylib 과 C 런타임은 정적 링크되어 있습니다.
