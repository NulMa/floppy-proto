1. **저작권·라이선스 고지를 같이 배포한다.** 단일 exe 라서 파일을 옆에 못 두므로

2. **폰트만 따로 팔 수 없다.** 게임에 실어 배포하는 건 명시적으로 허용된다
3. **예약 폰트 이름**이 `Neo둥근모` · `NeoDunggeunmo` (및 `~ Code`) 다.
   고쳐서 쓰면 **그 이름을 쓰면 안 된다** — 아래 아틀라스가 여기 걸린다

> 원본인 **둥근모꼴**(김중태, 90년대)은 퍼블릭 도메인이다. OFL 고지가 부담이면
> 원본 비트맵으로 내려가는 길도 있다. 다만 neoDGM 이 추가한 문자·기호는 못 쓴다.

## 이 TTF 를 exe 에 그대로 넣을 수는 없다

**651,044 B > 여유 444,416 B.** 그리고 TTF 경로는 `stb_truetype` 를 끌어와서
**고정비가 +38,912 B** 더 붙는다 (`게임스펙.md §9` 실측).

## 그래서 — 아틀라스로 굽는다

neoDGM 은 **16×16 비트맵 폰트(둥근모꼴)를 TTF 로 옮긴 것**이라, 16px 로 찍으면
픽셀 격자에 정확히 떨어진다. 실제로 확인했다 (2026-08-19):

```
512 음절을 16x16 격자로 렌더 (SingleBitPerPixelGridFit)
  → 알파값이 0 과 255 **두 개뿐** — 안티에일리어싱이 전혀 없다
  → png 21,317 B = 글리프당 41.6 B
```

| | 값 |
|---|---|
| 아틀라스 (512 음절) | 21,317 B |
| 실제 필요 (힌트·메뉴만 번역, 터미널 표기는 영문) | 200~300 음절 → **8~13 KB** |
| `LoadFontFromImage` 고정비 | +2,048 B |
| 한글 문자열 (UTF-8 3바이트) | +약 6 KB |
| **합** | **약 20 KB (예산의 1.4%)** |

★ **글자 높이가 16px 이다.** 지금 UI 는 raylib 기본 10px 이고 화면은 288px 다.
   한글 한 줄이 화면 높이의 5.5% 를 먹는다 (영문 10px 은 3.5%). 힌트가 2~3줄이면
   차이가 크다 — **레이아웃을 다시 재야 한다.** 12px 로 줄이면 픽셀이 깨진다.

굽는 도구는 아직 없다. `tools/png2c.ps1` 옆에 `make-font-atlas.ps1` 로 넣으면 된다.
